    Configurazione della pubblicazione su YouTube

    Una tantum, gratis, ~15 minuti. Il Client ID è un identificativo pubblico: nessun segreto in gioco.

    Hai aperto l'app da un file locale (file://). L'accesso con Google funziona solo da un vero indirizzo web: usa il sito su GitHub Pages o un server locale (serve.ps1).

    1. Apri la Google Cloud Console e crea un progetto (nome qualsiasi, es. TopFratmRanks).

    2. Attiva la YouTube Data API v3.

    3. In Schermata consenso OAuth: scegli Esterno, compila i campi minimi, poi in Utenti di test aggiungi gli account Google che pubblicheranno (la tua email).
